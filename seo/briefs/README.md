# Content briefs

Written by the `seo-content-strategist` agent, filled in by a human.

A brief says what a page should cover, for which query, with which internal
links and schema — and lists what only the business can supply: the photos,
job details and real numbers that make a local page rank. Agents do not write
the pages themselves; see `.claude/skills/seo-audit/references/guardrails.md`.
